For this project i first started with the idea of just looking up a superhero and getting information about that superhero.
I switched that idea and decided to to a "SuperHeroFigther" instead based on Intelligence, Strength, Speed, Durability, Power, and Combat
It is going based of the data of https://www.superheroapi.com/ids.html
You will need an access token and the characters ID to use this program.
Go to the link provided and follow the instructions to get an access token and the characters IDs!
